# Maquettes statiques

Ces maquettes textuelles servent de repères pour les écrans principaux, indépendamment du gabarit commun qui sera fourni par Faneva.

## Vitrine des offres

```text
SIRH — Recrutement
[Rechercher une offre________________] [Rechercher]

Développeur·se web                         OFF-2026-0001
Résumé du poste…                           Date limite : 30/11/2026
[Consulter et postuler]

← 1  2  3 →       [Déposer une candidature spontanée]
```

## Formulaire candidat

```text
Postuler — Développeur·se web
Identité : [Nom] [Prénom] [E-mail] [Téléphone]
CV numérique : [Études] [Expérience] [Compétences + Ajouter]
               [Formations] [Expériences] [Langues] [Disponibilité]
CV PDF ou DOCX (5 Mo maximum) [Choisir un fichier]
[Envoyer ma candidature]
```
