# =============================================================================
#  Ordre canonique des migrations SIRH — SOURCE UNIQUE
#  Lu par scripts/migrations.sh et scripts/recette-locale.sh : ajouter ici
#  toute nouvelle migration, à la fin, jamais au milieu.
#
#  Colonnes séparées par « | » :
#    fichier     nom du fichier dans migrations/
#    type        schema      : structure (+ référentiel indispensable), toujours appliqué
#                base        : comptes, départements, postes, budgets — toujours appliqué
#                test        : données de démonstration, seulement avec --avec-donnees-test
#    destructif  oui si le fichier commence par DROP TABLE … CASCADE : il efface les
#                données existantes, il ne doit JAMAIS être rejoué sur une base en service
#    marqueur    expression SQL vraie si la migration est déjà présente dans la base
#                (sert à reconnaître une base créée avant le suivi des migrations)
# =============================================================================
